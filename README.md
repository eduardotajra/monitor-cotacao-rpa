# Monitor de Cotação Fullstack

Solução de RPA e Monitoramento de Câmbio.

## Estrutura

* **/backend:** API Express + Puppeteer + PostgreSQL.
* **/frontend:** Interface Next.js + React TS.

## Como rodar

### 1. Backend

```bash
cd backend
npm install
# Crie o arquivo .env com DB_PASSWORD
node server.js
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```
